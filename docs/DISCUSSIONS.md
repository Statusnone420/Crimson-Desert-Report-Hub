# Discussion Guide

Use GitHub Discussions for questions, ideas, setup help, and community coordination that is not yet a concrete bug or scoped feature request.

## Good Discussion Topics

- Setup help for local development or deployment.
- Questions about Supabase, Vercel, Cloudflare Turnstile, capped public-web discovery, bounded server-side enrichment, routine fallback behavior, or the source radar.
- Ideas for improving report quality or moderation flow.
- Public Crimson Desert source suggestions.
- Corrections to original reporting, source attribution, or selected press and creator coverage.
- Confirmation-board wording, privacy, or patch-family behavior.
- Community triage notes that need conversation before becoming issues.

## Use Issues Instead For

- Reproducible app bugs.
- Small, scoped feature requests.
- Broken docs links.
- Failing tests or CI problems.
- Accessibility problems with a clear affected page.

## Do Not Post Publicly

- API keys, passwords, tokens, or `.env.local` contents.
- Screenshots with credentials or private dashboard URLs.
- Private player messages, emails, or support tickets.
- Raw crash logs that include personal paths, usernames, or machine identifiers.
- Unmoderated report exports from production.

## Helpful Discussion Format

```text
Title: Short summary of the question or idea

Context:
- What are you trying to do?
- What page, route, provider, or command is involved?

What happened:
- Paste safe errors or screenshots with secrets removed.

What you expected:
- Describe the result you wanted.

Links:
- Public URLs only. No tokens, private dashboards, or invite-only pages.
```

## Suggested Pinned Welcome Post

```markdown
Welcome to Crimson Desert Report Hub Discussions.

Use this space for setup help, public source suggestions, reporting corrections, and broader ideas for the newspaper and player record. Keep secrets, credentials, private support tickets, and raw personal logs out of public posts.

For concrete app bugs or scoped feature requests, open an issue instead.
```
