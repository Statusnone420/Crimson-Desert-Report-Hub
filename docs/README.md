## Documentation rules

- Describe observed behavior, not intended behavior, unless a page is clearly a proposal.
- Keep reports, check-ins, scanner leads, and official claims separate in every public explanation.
- Never publish secrets, raw report text, private source candidates, network hashes, or private dashboard details.
- Update this index when you add a page or change a route, provider, migration workflow, or budget boundary.
